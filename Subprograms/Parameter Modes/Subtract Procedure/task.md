## Exercise: Subtract procedure

The same subtraction as before, written as a procedure that hands its answer back through an `out`
parameter.

```adasnippet
procedure Subtract_Procedure (A, B : Integer; Result : out Integer);
```

> [!NOTE]
> The original lab calls this `Subtract`, the same name as the function version. One GNAT project
> is one namespace, so this one carries the longer name.
