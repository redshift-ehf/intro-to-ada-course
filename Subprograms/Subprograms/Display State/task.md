## Exercise: States

A machine has three states, numbered 0, 1 and 2. Write a procedure that prints the name of the
state it is given.

```adasnippet
procedure Display_State (State : Integer);
```

| State | Output |
|---|---|
| 0 | `Off` |
| 1 | `On: Simple Processing` |
| 2 | `On: Advanced Processing` |

The text must match exactly — the tests compare what you print.

Press **Check** when you are done.
