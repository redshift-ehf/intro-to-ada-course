## Exercise: Subtract function

Write a function that subtracts `B` from `A` and returns the result.

```adasnippet
function Subtract (A, B : Integer) return Integer;
```

> [!NOTE]
> The original lab calls this function `Subtract`, and so does the next exercise, which writes the
> same operation as a procedure. This whole course is one GNAT project, so two library-level units
> cannot share a name — here the function keeps `Subtract` and the procedure becomes
> `Subtract_Procedure`.

Press **Check** when you are done.
