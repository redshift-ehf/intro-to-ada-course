# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be respectful, assume good faith, and remember what this repository is. It is a course for
people meeting Ada for the first time, and the questions it attracts will often be beginners'
questions. Answering one impatiently costs more here than it would elsewhere, because the person
asking is deciding whether the language is worth their time.

Ada also draws people from safety-critical work, who arrive with deep experience and strong opinions
about how it should be taught. Both audiences are welcome, and neither gets to talk down to the
other.

## Reporting

Report unacceptable behaviour by opening a
[private security advisory](https://github.com/redshift-ehf/intro-to-ada-course/security/advisories/new)
on this repository, which is visible only to maintainers, or by emailing **developer@redshift.is**.
Reports are handled confidentially.
